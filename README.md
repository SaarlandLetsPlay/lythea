## 🤔 Was ist Lythea?

Lythea ist ein Discord-Bot mit eigenem Web-Dashboard. Du aktivierst die Module, die du brauchst, und konfigurierst sie im Browser. Befehle musst du dafür nicht auswendig lernen.

## ✨ Highlights

| | Feature | Worum es geht |
| :---: | :--- | :--- |
| 📊 | **Analytics** | Wachstum und Aktivität deiner Community, dazu Statistik-Kanäle |
| 📻 | **Radio** | Integriertes Radio-Modul für Stimmung auf dem Server |
| 📧 | **Newsletter** | Nachrichten an deine Mitglieder, direkt aus dem Dashboard |
| 🎫 | **Tickets** | Support-Tickets mit Transkripten und Team-Zuweisung |
| 🛡️ | **Auto-Moderation** | Filter, Keyword-Erkennung und Regeln gegen Spam und Störer |
| 🎭 | **Automatisierung** | Level, Rollen, Willkommensnachrichten und mehr |

## 🧩 Module

Jedes Modul schaltest du pro Server einzeln ein oder aus.

| Bereich | Module |
| :--- | :--- |
| 🏆 **Community** | Level · Economy · Achievements · Starboard · Geburtstage · Giveaways · Umfragen · Counting · Boost-Belohnungen |
| 🛡️ **Moderation** | Auto-Moderation · Keyword-Filter · Regeln · Traps (Bann-Falle) · Monitoring |
| 🎭 **Rollen & Begrüßung** | Selfrole · Willkommensnachrichten |
| 🔊 **Kanäle & Sprachchat** | Voice-Räume · Voice-XP · Statistik-Kanäle |
| 📺 **Inhalte & Medien** | Live-Benachrichtigungen (Streams) · VOD · Radio · Newsletter · Custom Commands |
| 🎮 **Spiele & Extras** | Games · Minecraft-Anbindung · Verkauf (Sales) |
| 🎫 **Support** | Ticket-System |

## 🚀 So funktioniert's

1. **Bot einladen** über die Website
2. **Im Dashboard anmelden** und deinen Server auswählen
3. **Module aktivieren** und nach deinen Wünschen einstellen
